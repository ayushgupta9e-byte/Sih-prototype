# Judge Demo Flow

1. Open the app.
2. Tick consent.
3. Choose **Text only** and enter a neutral sample. Show LOW/low SVI.
4. Create a second case using **Voice only**. Speak a demo narrative; show transcript, speech interaction metrics and SVI.
5. Create a third case using **Text + Voice**. Show that both sources are combined before NLP assessment.
6. On the result, add a missing detail under **Add missing information to the same case**.
7. Click **Add information & re-analyze**.
8. Show that the same Case ID remains while narrative, NLP factors and SVI are recalculated.
9. Open Officer Dashboard.
10. Explain that the AI score is a screening/prioritization signal; authorized humans make final decisions.

Do not use real victim information in a demo. Use synthetic/demo text only.
